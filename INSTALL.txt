ULTRAKILL TAS Tool - install
============================

You need
--------
1. ULTRAKILL on Steam (latest version).
2. BepInEx 5 (64-bit), installed into ULTRAKILL once.
   BepInEx is the mod loader. UKTAS runs inside it.
   Download BepInEx_win_x64_5.4.x from
   https://github.com/BepInEx/BepInEx/releases
   Unzip it next to ULTRAKILL.exe, then start the game once and close it.
   Skip this if you already have BepInEx 5 in ULTRAKILL.

Install
-------
1. Close ULTRAKILL.
2. Find your game folder: Steam > right-click ULTRAKILL > Manage >
   Browse local files. It is the folder that contains ULTRAKILL.exe.
3. Open this zip. Drag the "ultrakill" folder onto your ULTRAKILL game folder.
4. Click Replace / merge if Windows asks. Accept the admin prompt if shown.
5. Start ULTRAKILL.

Use
---
- Press Insert in game to open the TAS window.
- A "loaded" message shows in the top-right corner when the mod is running.
- User guide: UKTAS_DOCS.html (in this zip, open it in a browser).

Where things live (inside the ULTRAKILL folder)
-----------------------------------------------
- Plugin:   BepInEx\plugins\UltrakillTAS\UltrakillTAS.dll
- Config:   BepInEx\config\com.tas.ultrakill.cfg
- Scripts:  BepInEx\config\ULTRAKILL-TAS\   (examples are in the examples subfolder)
- Log:      BepInEx\LogOutput.log

Uninstall
---------
Delete the folder BepInEx\plugins\UltrakillTAS.
Optional: also delete BepInEx\config\ULTRAKILL-TAS and
BepInEx\config\com.tas.ultrakill.cfg to remove your scripts and settings.
